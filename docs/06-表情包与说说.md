# 一、表情包

## 1.1 先修那个必然踩的坑

**症状**：发图时报 `图地址解析到内网被拦截`。

**原因**：SSRF 防护会拒绝解析到私有 IP 的地址。但很多代理软件（Clash 的 fake-ip 模式）会把**所有域名**解析成 `198.18.x.x` 这种保留地址，于是正常公网图片也被当成内网。

**修法**：打 `0004-safe-fetch-fakeip.patch`，把 fake-ip 网段加进白名单：

```js
// src/safe-fetch.js
const FAKE_IP_RANGES = ['198.18.0.0/15', '198.19.0.0/16'];
```

或者关掉代理的 fake-ip 模式（改成 redir-host）。

## 1.2 灌一批表情包

qq-bridge 的表情包存在：

```
~/dafeiyu/qq-bridge/data/stickers/      # 原图
~/dafeiyu/qq-bridge/data/stickers_small/ # 缩略图
```

从网上下载的表情包合集（很多 GitHub 仓库有），丢进 `stickers/`，然后让 bridge 重建索引。

**格式建议**：

- **静态图**：`.png` / `.jpg`，建议 240×240 以内
- **动图**：`.gif`，控制在 500 KB 以内（QQ 有大小限制，太大发不出去）

批量转小：

```bash
# 用 sips（macOS 自带）
for f in stickers/*.png; do
  sips -Z 240 "$f" --out "$f"
done
```

## 1.3 表情包规则（进提示词）

光有图不够，模型得知道**什么时候用**。`0005` 补丁里已经写了，核心是：

```markdown
- 回表情：别人用表情回你时，约七成也回一张
- 斗图：对方连发、明显逗你时可以斗，2~3 轮就收
- 频率：普通闲聊约 3~5 轮一张；别每条都只发表情
- 严肃/正式/敏感话题别硬塞
```

**这几个数字是有用的**——「约七成」「3~5 轮」这种具体数值，比「适度使用」有效得多。

## 1.4 让它自己收藏

补丁里带了 `qq_collect_sticker` 工具。模型看到有意思的图会自己存，写一条备注（比如"好图偷了"），下次就能按语境检索。

**约束**：告诉它「不要频繁收藏」。不然它会把什么图都存下来，索引很快变成垃圾堆。

# 二、空间说说

## 2.1 能力清单

补丁加了三条路由 + 对应 MCP 工具：

| 工具 | 作用 |
|---|---|
| `qq_qzone_send` | 发说说，支持文字 + 图片 + 权限（谁可见） |
| `qq_qzone_list` | 看好友的说说 |
| （SnowLuma 原生） | 点赞、评论、删说说、看自己的资料 |

## 2.2 用法

发一条纯文字的：

```javascript
// AI 会自己调，你不需要写代码
qq_qzone_send({ content: "今天天气不错，出去走了走" })
```

发带图的：

```javascript
qq_qzone_send({
  content: "新买的杯子",
  images: ["/绝对路径/cup.jpg"],   // 支持多张
  ugc_right: 1                     // 1=公开 3=好友 4=仅自己
})
```

## 2.3 注意

- **图片路径必须是 SnowLuma 能访问到的**。在容器方案里，图片要先 `docker cp` 进去，或者用 base64 —— 同 `99-踩坑总表.md` C3。
- **频率**：说说是公开内容，别让它刷。建议在人格卡里写「一天最多一条，想起来才发」。
- **权限默认好友可见**，别默认公开。

# 三、长期记忆

## 3.1 为什么需要

默认的会话记忆是**上下文窗口**，聊得久了前面的就忘了。换一天再聊，它完全不记得你昨天说过什么。

长期记忆把重要事实抽出来存成向量，下次对话前检索相关的几条塞回去。

## 3.2 装

`0002-long-memory.patch` 加了 `src/long-memory.js`，存储用 SQLite + 向量相似度。

**需要一个 embedding 服务**。推荐硅基流动（有免费额度）：

```json
{
  "memory": {
    "enabled": true,
    "embedding": {
      "apiBase": "https://api.siliconflow.cn/v1",
      "apiKey": "<你的 key>",
      "model": "BAAI/bge-m3"
    }
  }
}
```

`bge-m3` 是 1024 维，中文效果好，而且免费。

**不想用云端**：本机 Ollama 也能跑：

```bash
ollama pull bge-m3
# apiBase 改成 http://127.0.0.1:11434/v1
```

## 3.3 它会记什么

工具 `qq_memory_remember` 只记**对方亲口说过、或明确能看出来**的事实：

- ✅ 「在杭州」「养了只橘猫叫豆豆」「不吃香菜」
- ❌ 「今天心情不好」（临时的，不该记）
- ❌ 你自己推测的东西

检索的时候用自然语言，不需要关键词匹配：

```
qq_memory_recall({ query: "她还喜欢猫吗" })
```

## 3.4 维护

```bash
# 看存了多少条
curl -H "x-console-token: <token>" http://127.0.0.1:3100/api/memory/stats

# 忘掉某个人
qq_memory_forget({ uid: "..." })

# 全清（慎用）
qq_memory_clear()
```

建议每月看一眼，把过期的删掉。记忆堆太多反而会检索出无关的东西。

---

## 这三件事的共同点

都不是"装个插件就能用"，都要**改提示词**。

能力（API）只决定能不能做，提示词决定**该不该做、什么时候做、做多少**。后面这半部分才是"像人"的关键。
